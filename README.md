# Куда пропадают подписчики после знакомства с твоим ботом?

Отдельный интерактивный чек-лист для нутрициологов. Не заменяет аудит реального бота.

**Ссылка:** https://checklist.avdeeva-ludmila.ru/bot-subscribers/

## Что внутри

- Пять согласованных ситуаций из пути нового подписчика.
- Для каждой: пример «Как бывает», три вопроса «Проверь у себя», галочка.
- Результат самопроверки с главным выводом, возможной причиной, конкретными действиями и примерами «было → стало».
- Дополнительные отмеченные проблемы раскрываются отдельно; предусмотрен сценарий без отмеченных проблем.
- Кнопка «Изменить ответы» сохраняет выбранные пункты.
- В финале — согласованный текст с приглашением в Telegram и ВКонтакте:
  - https://t.me/avdeeva_blog
  - https://vk.ru/avdeeva__blog
- Никаких форм контактов, рассылок или автоматической отправки результатов.

## Техника

React + TypeScript + Vite + Tailwind CSS. Исходник самодостаточен; изображения в public/images/*.webp.

    npm ci
    npm run lint
    npx tsc -b
    npm run build

Конфигурация Vite использует base: /bot-subscribers/. Для локального dev-сервера можно запускать npm run dev.
Проверка в браузере выполнена на ширинах 320, 390 и 1366 px: все пять одиночных результатов, пустой результат, несколько отмеченных ситуаций, возврат к ответам, ссылки и картинки.

## Размещение

- Компьютер: /home/proekt/checklists/subscriber-journey-checklist/
- Сервер: /opt/checklists/bot-subscribers/
- Статические файлы: /opt/checklists/bot-subscribers/dist/
- Действующая конфигурация Caddy с новым маршрутом: /opt/checklists/bot-subscribers/Caddyfile.candidate

На сервере схема /bot-subscribers/* добавлена через caddy reload с полной объединённой конфигурацией, сохраняя /nutri/, корневой чек-лист и bot-audit. Текущий /etc/caddy/Caddyfile недоступен для записи из подключённого инструмента. **После системного перезапуска сервиса Caddy новый маршрут может пропасть**: администратору нужно перенести конфигурацию из Caddyfile.candidate в /etc/caddy/Caddyfile или повторно применить её. То же замечание относится к ранее добавленному /nutri/.

На компьютере для тестовой локальной сборки node_modules временно связан с /home/proekt/portfolio-avdeeva-ludmila/node_modules, поскольку npm-прокси в момент сборки был недоступен. Позже при рабочем npm можно переустановить зависимости через npm ci.

Отдельный GitHub-репозиторий пока не подключён. Не менять исходные проекты универсальных чек-листов.
